# Misión

## Qué construimos

Una aplicación web para empresarios colombianos que permite gestionar cuentas de cobro, clientes, acreedores e ítems. Facilita crear y actualizar cuentas y generar su documento.

## Para quién

- Empresarios colombianos que necesitan registrar sus clientes y acreedores y dar seguimiento a sus cuentas de cobro.

## Principios

- **Claridad operativa:** facilitar la consulta y edición de datos de trabajo.
- **Separación por usuario:** las consultas de dominio observadas emplean el identificador del usuario; la cobertura de autorización debe verificarse para todas las operaciones.
- **Validación:** validar entradas en frontend y backend conforme a las instrucciones del proyecto.
- **Evolución guiada por especificaciones:** especificar y planear antes de implementar cambios nuevos.

## Alcance

La aplicación implementa gestión de información y generación de PDF. No se ha encontrado evidencia suficiente para afirmar que procese pagos o integre contabilidad.
