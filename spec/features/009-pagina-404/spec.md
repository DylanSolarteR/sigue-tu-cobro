# 009 · Página 404

**Estado:** pendiente

## Qué hace

Mostrar una página útil cuando una ruta no exista.

## Por qué

Orientar al usuario cuando llega a una dirección inválida.

## Criterios de aceptación

Estos criterios requieren verificación; la presencia de código o el TODO del README no demuestra su cumplimiento.

- [ ] Una ruta inexistente muestra una página 404 clara.
- [ ] La página ofrece una forma de volver a un lugar útil.
- [ ] La solución funciona en los tamaños admitidos.

## Fuera de alcance

- No incluye otros estados de error.
