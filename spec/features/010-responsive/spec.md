# 010 · Adaptación responsive

**Estado:** pendiente

## Qué hace

Adaptar la aplicación a distintos tamaños de pantalla.

## Por qué

Permitir usar los flujos principales en móviles y otros dispositivos.

## Criterios de aceptación

Estos criterios requieren verificación; la presencia de código o el TODO del README no demuestra su cumplimiento.

- [ ] Las rutas y formularios principales son utilizables en móvil y escritorio.
- [ ] Las tablas y la navegación siguen siendo accesibles en pantallas estrechas.
- [ ] No existe desbordamiento que impida realizar las tareas principales.

## Fuera de alcance

- Los tamaños y solución exacta deben decidirse durante la planificación.
